## ⭐ Projeto em destaque: Athena

POC de assistente de IA em formato de chat que funciona como "oráculo" do ecossistema de microsserviços da empresa: qualquer pessoa pergunta em linguagem natural como o sistema funciona e recebe a resposta, sem depender de documentação dispersa ou de quem conhece o código.

- **Problema:** conhecimento do sistema concentrado em poucas pessoas e no código, inacessível para quem não é técnico.
- **Solução:** extrator baseado em AST que lê o código dos microsserviços e gera um catálogo padronizado; RAG com Claude sobre esse catálogo responde perguntas técnicas e funcionais.
- **Resultado:** 60+ microsserviços catalogados em uma base consultável por devs, POs, gerentes de projeto e suporte.

> Projeto interno, por isso o código não é público.
